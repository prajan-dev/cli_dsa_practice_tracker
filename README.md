# CLI DSA Practice Tracker

A Python based command line application to track Data Structures & Algorithms (DSA)  problems with full CRUD operations and JSON based data storage.

## Features
- Add DSA problem with details (platform, difficulty, topic)
- View all saved problems
- Update problem status (Solved / Unsolved / Revisiting)
- Delete problems
- Persistent storage using JSON file
---------------
## Tech Stack
- Python
- JSON (File Storage)
- Object-Oriented Programming (OOP)
----------------
## Project Structure
- main.py-> Entry point
- tracker.py -> Core logic (CURD operations)
- models.py -> Data model (Problem class)
- data.json -> Storage file
----------------
## Learning Outcome
- CURD operations in Python
- File handling using JSON
- OOP concepts (classes & objects)
- CLI based application design
